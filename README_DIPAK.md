# Dipak — Day 1 package catalogue UI

## Add these files (do not replace existing files)
- `app/templates/packages/listing.html`
- `app/templates/packages/_card.html`
- `app/templates/packages/details.html`
- `app/static/css/packages.css`

These are the first catalogue templates. They expect a future `packages` blueprint with endpoints `packages.listing` and `packages.details`, and a customer booking endpoint `customer.book_package`. They will become accessible when the routes are added on later days. Do not edit `app/routes.py` or `app/__init__.py` on Day 1.
